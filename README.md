**Projects**

**1. Event Budget Exception Report & Dashboard**

Folder: Event-Budget-Exception-Report/

Tools Used: Excel, Nested IF/IFS, Cross-Sheet Formula Linking, Conditional Formatting, COUNTIF, SUM

Project Highlights


Built a 3-sheet live reporting system: raw source data → exception report → leadership dashboard.
Applied exception-reporting discipline — only budget items with significant variance are surfaced for review, following management-by-exception principles.
Classified every line item as Red (>15% variance), Amber (8-15%), or Green (on track) using nested IF/IFS logic.
Designed a dashboard summarizing total items tracked, exception count, and net variance, with an escalation table for items needing management attention.
All figures fully formula-driven with live cross-sheet references — no hardcoded values, so the report recalculates automatically if source data changes.


Key Insight

Out of 10 event budget line items, 3 were flagged for escalation (30% exception rate), isolating a ₹17,500 net overspend for management review — without requiring a full manual review of every line item.
